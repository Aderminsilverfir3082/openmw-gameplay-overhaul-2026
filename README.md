## 🛠️ Frequently Asked Questions

### Do I need to install all mods separately?
No. The package is pre-assembled. You run one installer. All mods are integrated and load in the correct order.

### Will this break my existing save game?
It is highly recommended to start a new character. Existing saves might work, but the new mechanics (like different enemy stats) can feel strange. Start fresh for the best experience.

### Is OpenMW itself included?
No. You must have OpenMW installed (version 0.48 or newer). If you do not have it, download it for free from the official OpenMW website. It is a legal replacement engine that runs your original Morrowind disc or GOG/Steam copy.

### I made a mistake. How do I uninstall?
Run the installer again and choose "Uninstall." It removes all changes cleanly and restores your original settings.

### What if I have other mods installed?
This package works best alone. If you have other mods installed, disable them before running the installer to avoid conflicts. You can re-enable them later, but results may vary.

## 🔧 Troubleshooting

**"The installer says it can't find OpenMW."**
Manually browse to the folder that contains `openmw.exe`. This is usually inside `C:\Program Files\OpenMW` but could be different if you use Steam.

**"The game crashes at startup."**
Make sure you have the latest version of OpenMW. Also, check that your Morrowind data files (the original game) are installed properly. The mods assume you have the base game.

**"Text looks weird or missing."**
Rare font issue. Re-run the installer and select "Repair" option. This resets font configuration.

**"I want vanilla back."**
Run the installer, choose "Uninstall," and restart OpenMW. Your game goes back to normal. No trace left behind.
